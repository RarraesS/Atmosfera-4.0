
# Atmosfera 4.0
Projeto escolar da Escola SENAI Anchieta para monitoramento ambiental por meio de sensores.
O sistema integra banco de dados MySQL, back-end Java com Spring Boot e páginas web para visualização e simulação de medições ambientais.

## Pastas do projeto
- [Dashboard](dashboard/): página de monitoramento com indicadores ambientais, histórico das últimas 24 horas e lista de dispositivos.
- [IoT_Robot](IoT_Robot/): simulador que gera valores ambientais aleatórios e envia medições periodicamente para a API.

## Tecnologias utilizadas
- HTML
- CSS
- JavaScript
- Java e Spring Boot
- MySQL

## Execução local
O back-end e o MySQL devem estar em execução no computador. As páginas web podem ser abertas com o Live Server do VS Code para testar a integração local.
Projeto desenvolvido para aprendizado e práticados conhecimentos adquiridos.
